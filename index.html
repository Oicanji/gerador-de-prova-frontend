Importar pacote PR (.pr)

O ficheiro .pr é um ZIP com principal.md (texto no formato do gerador: blocos com pergunta:, opcionalmente # meta), todo arquivo gerado aqui com extensão .pr é feito exclusivamente para o uso dessa ferramenta.

Metadados

Use o somente pacote .pr importado no topo.

Cada geração grava só o último lote no .pr. Execuções antigas ficam em pastas output/runs/… (lista em output/runs-index.json); na linha de comando use --ordens runs/nome-da-pasta no restaurar se não for a última.

As questões e ids Q1, Q2, … têm de coincidir com o principal.md da geração.
